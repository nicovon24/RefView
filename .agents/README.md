# Project-local R3F agent skills

The 11 directories under `skills/` were copied from
[`EnzeD/r3f-skills`](https://github.com/EnzeD/r3f-skills) at commit
`4a11805f097396fb0b893172efd1e359e8051f92` using Codex's
`install-skill-from-github.py` with `--dest .agents/skills`.
The upstream README states an MIT license; that commit does not contain a
standalone `LICENSE` file. No npm packages were installed by this step.

Installed skills: `r3f-fundamentals`, `r3f-geometry`, `r3f-materials`,
`r3f-lighting`, `r3f-textures`, `r3f-loaders`, `r3f-animation`, `r3f-shaders`,
`r3f-postprocessing`, `r3f-interaction`, and `r3f-physics`.

RefView's authored timeline and facts remain canonical. Animation and physics
guidance may improve presentation and movement but must not determine the
reviewed incident or its score. Check examples against the versions pinned in
`apps/web/package.json` before using them.
