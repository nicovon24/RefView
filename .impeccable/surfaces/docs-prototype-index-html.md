# RefView complete product prototype

Mode: Operate. Audience: referees in training first, with an approachable path for fans, players, coaches, and beginners. Job: evaluate the complete product flow while keeping the simulator as the dominant experience. Primary action: enter a scenario, observe, decide, and learn. Content is illustrative unless explicitly linked to a reviewed rule source.

## Direction contract

THESIS: RefView feels like directing a live match, not operating a sports dashboard. The field leads; navigation, metrics, and learning tools yield until the action ends.

OWN-WORLD: Natural pitch and stadium colour, deep green-black chrome, off-white type, lime selection, turquoise referee cues, and coral decision states. Controls are compact, opaque, rectangular, and readable over motion. Photography-like game frames own simulator surfaces; quiet light surfaces own reading.

STORY: The user enters behind the referee, changes distance or first-person view, judges one canonical incident, then sees exactly which evidence was available, how the Laws apply, and what to practise next. The same evidence model connects Academy, Community, Assessments, and Profile.

FIRST VIEWPORT: A narrow top bar frames a near-full-screen 16:9 match engine view. The referee sits low-centre, the decisive challenge ahead, with only match time, camera mode, communications, movement hints, and a compact decision panel visible. Navigation recedes into an overlay and returns outside live play. Signature interaction: C switches between third-person and first-person without changing the canonical timeline.
