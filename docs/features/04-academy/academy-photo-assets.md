## Origin and use

The 20 files in `apps/web/public/assets/academy/law-photos/` were generated for RefView on 2026-11-05 with the built-in OpenAI image generation tool. They are original synthetic scenes, not photographs of real matches, official IFAB artwork, or evidence for a refereeing decision. No third-party image asset or rule excerpt is embedded in these files. The application labels each scene as generated in Spanish and English.
